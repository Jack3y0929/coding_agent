### 1. `index.html` 关键设计（决定 P0「双击可开」）

```
<!doctype html> / <html lang="zh-CN"> / charset=utf-8 / viewport
<head>  <title>Hello DEV</title>
        <link rel="stylesheet" href="style.css">   ← 相对路径，禁止 /style.css
<body>
  <main class="card">
    <h1 id="greeting" class="greeting">Hello DEV</h1>   ← 初始文案硬编码在 HTML 内（JS 未执行也能看到）
    <button id="toggle-btn" type="button" class="btn">点我运行工作流</button>
  </main>
  <script src="script.js" defer></script>          ← 无 type="module"
</body>
```

**硬约束落实**：
- 不加 `type="module"`（file:// 下 ES Module 触发 CORS 拦截 → 静默失效）。
- 不引外部字体/CDN/网络请求；`favicon` 不额外引用（避免 file:// 下 404 噪声）。
- `<h1>` 内直接写死 `Hello DEV`，保证「页面显示 Hello DEV」这条标准不依赖 JS 是否加载成功。

### 2. `style.css`

- `box-sizing` 重置 + `body{display:grid;place-items:center;min-height:100vh}` 居中卡片。
- `.greeting` 字号/字重；`.greeting--success` 仅用于成功态的强调（变色），**文案由 JS 控制，CSS 不写 content 文案**（防止 DOM 文本断言取不到字）。
- `.btn` 含 `:hover/:focus-visible/:active` 三态；无动画库、无 @keyframes 花活。

### 3. `script.js`（数据流 + 异常处理）

```
(function () {
  'use strict';
  var SUCCESS_TEXT = 'DEV 工作流运行成功';   // 常量集中，逐字符核对：无引号、无首尾空格
  // 兜底绑定：readyState 已 complete 时直接初始化，否则等 DOMContentLoaded
  // init(): querySelector('#greeting') / '#toggle-btn'
  //   若任一为 null → 直接 return（不抛错），可选 console.warn 一次
  //   btn.addEventListener('click', handler)
  // handler(): greetingEl.textContent = SUCCESS_TEXT;
  //            greetingEl.classList.add('greeting--success');
  //            btn.setAttribute('data-run','1');   // 幂等，重复点击结果一致
})();
```

**数据流**：用户点击 → click 事件 → handler → 写 `textContent`（单一数据源，无状态存储、无 DOM 结构变更）→ 浏览器重排渲染。

**幂等设计取舍**：需求为「单次点击生效 + 结果可重复触发」→ 采用**重复点击安全（幂等覆写）**，不 `disabled` 按钮；避免与「可重复触发」解读冲突。

**异常处理策略**：
- 元素缺失 → 静默 return，不抛未捕获异常（控制台零报错是 P0）。
- 用 `textContent` 而非 `innerHTML`，避免任何 HTML 解析歧义，保证精确文本。
- IIFE + `'use strict'`，不污染 `window`，多次插入脚本也安全。
