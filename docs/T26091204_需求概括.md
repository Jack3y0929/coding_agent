# 需求概括 · hello-dev 静态演示页

## 1. 项目定义
在空目录 `D:\ABC` 下新增一个零依赖的原生前端最小演示：加载显示 "Hello DEV"，点按钮切换为 "DEV 工作流运行成功"，用于验证 DEV 工作流端到端可跑通。

## 2. 核心功能范围

**做：**
- 新建 `hello-dev/` 目录及 4 个文件：`index.html`、`style.css`、`script.js`、`README.md`
- HTML 初始渲染 "Hello DEV" 文本节点（非占位空串）
- 一个按钮，点击 → 文本内容替换为 "DEV 工作流运行成功"（单向替换，无还原要求）
- CSS 外置到 `style.css`，通过 `<link>` 引入；JS 外置到 `script.js`，通过 `<script>` 引入
- 事件绑定用 `addEventListener`，脚本置于 DOM 之后或用 `DOMContentLoaded`，避免 null 引用
- `README.md` 覆盖：目录结构表 + 打开方式（双击 `index.html`）+ 交互说明 + 验证方式
- 交付前执行 JS 语法检查（`node --check hello-dev/script.js`），并把命令与输出写进 README 或提交说明

**不做：**
- 不引框架、不引 CDN、不引构建工具、不引包管理器（无 `package.json`）
- 不修改 `D:\ABC` 下任何现有文件；不新增第 5 个文件（测试、配置、图标一律不要）
- 不做持久化（localStorage）、不做动画/主题/响应式适配、不做多语言
- 不做服务端、不做 `file://` 与 `http://` 差异处理（当前功能在 `file://` 下即可跑通）

## 3. 技术约束
- 原生 HTML5 + CSS3 + ES2015+ JavaScript，三个资源文件彼此独立，禁止内联脚本逻辑（HTML 结构除外）
- 全部相对路径引用，保证双击直开（`file://` 协议）可用——这意味着**不能用 `type="module"` 加载 `script.js`**（Chrome 等浏览器在 `file://` 下会因 CORS 拦截 module 脚本），用普通 `<script src>` 即可
- 无外部网络请求、无字体/图标外链

## 4. 关键验收标准（按优先级）
1. `hello-dev/` 目录及 4 个文件全部存在，项目其他路径零改动
2. 双击 `index.html` 后浏览器控制台**无报错、无 404**，页面可见 "Hello DEV"
3. 点击按钮后同一文本元素内容变为 "DEV 工作流运行成功"，且可重复点击不异常
4. 源码中检索不到 Vue / React / 第三方库 / 外链资源引用
5. JS 语法检查通过（`node --check` 退出码 0）；若环境无 node，退而用浏览器控制台无报错作为替代验证，并在 README 中注明
6. `README.md` 能让人不看代码就跑起来
