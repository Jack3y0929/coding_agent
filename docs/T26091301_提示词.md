## 1. 涉及文件（4 个，全部新建，无修改项）

### 1.1 `hello-dev/index.html`
**职责**：文案载体 + 资源挂接 + 交互锚点。

- `<html lang="zh-CN">`；`<meta charset="utf-8">` **必须是 head 首个 meta**（防 `file://` 双击中文乱码）；`<meta name="viewport">`；`<title>Hello DEV</title>`
- `<link rel="stylesheet" href="./style.css">` — **强制 `./` 相对路径**，禁用 `/style.css`（`file://` 下根路径解析到磁盘根，样式必然丢失 → 击穿 AC2）
- `<script src="./script.js" defer></script>` — **普通脚本 + `defer`**，**禁止 `type="module"`**（`file://` 下 module 触发 CORS 报错白屏）
- DOM 骨架：
  - `main.container`
    - `h1#greeting` → 初始文本硬编码 **`Hello DEV`**（文案落在 HTML，JS 失效时 AC1 前半段仍成立）
    - `p.hint` → 引导说明
    - `button#runBtn type="button"` → 文本 `运行 DEV 工作流`
    - `p#status` → 运行回显（次级证据，非验收项）

### 1.2 `hello-dev/style.css`
- 全局 `box-sizing: border-box`；`body` flex 居中 + 系统字体栈
- `.container` 卡片容器（宽度上限、padding、圆角、阴影）
- `#greeting` 字号/字重；`#greeting[data-state="success"]` 属性选择器切换成功色
- `button` 四态：`:hover` / `:active` / `:focus-visible` / `:disabled`（按钮态可感知 = style.css 已加载的视觉证据，支撑 AC2）
- 仅基础选择器；**不用 `@import`、不用外部字体、不写媒体查询断点**（需求明确排除响应式适配）

### 1.3 `hello-dev/script.js`
- `'use strict';` + IIFE 包裹，不污染 `window`
- 顶部常量：`SUCCESS_TEXT = 'DEV 工作流运行成功'`、`INITIAL_TEXT = 'Hello DEV'`、三个元素 id 常量
- 函数划分：
  1. `resolveElements()` — 取 `greeting` / `runBtn` / `status`；**任一 null 即返回 null 并 `console.error('缺少元素: #xxx')`**，不静默失败
  2. `handleRun(elements)` — `greeting.textContent = SUCCESS_TEXT`；`greeting.dataset.state = 'success'`；`runBtn.disabled = true`；`runBtn.textContent = '已运行'`；`status.textContent` 写运行痕迹
  3. `init()` — `readyState` 就绪守卫 + 绑定 `click`（`defer` 已保证 DOM 完成，仍加一层兜底增强健壮性）
- 一律使用 `textContent`（**禁 `innerHTML`**），无字符串拼进 HTML
- **零 `fetch`/`XMLHttpRequest`/`localStorage`/动态 `import`**
- 语法限定 ES2015~ES2017（`const/let`、箭头函数、模板字符串、`dataset`），本地现代浏览器直开无需 polyfill，且可被 `node --check` 解析

### 1.4 `hello-dev/README.md`
面向"不读代码即可验证"，五段：
1. 项目简介 + 零依赖声明（无 Vue/React/CDN/npm/node_modules）
2. **目录结构表**（文件 / 类型 / 职责）
3. **运行方式**：双击 `hello-dev/index.html`；无需任何服务器；样式未生效时检查同目录两文件是否齐全
4. **交互预期（验收对照表）**：初始文案 → 点击后文案 → 按钮态变化 → 控制台应无 error
5. **验证方式**：`node --check hello-dev/script.js`（在 `D:\ABC` 执行）+ 无 Node 时的降级验证步骤

## 2. 数据流设计

```
index.html 解析（charset 决定中文渲染正确性）
   ├─ <link ./style.css>            → 样式生效（视觉证据）
   └─ <script ./script.js defer>    → DOM 解析完成后执行 init()
         ├─ resolveElements()   读: 3 个 id | 写: 无 | 异常: 缺失 → console.error 并终止
         └─ 注册 runBtn 'click'
用户点击 → handleRun(elements)
   文案状态:  #greeting.textContent  "Hello DEV" ──click──▶ "DEV 工作流运行成功"（终态，单向）
   样式状态:  #greeting[data-state]  (无)        ──click──▶ "success"（CSS 属性选择器接管配色）
   按钮状态:  enabled / "运行 DEV 工作流"         ──click──▶ disabled / "已运行"（幂等防重）
   回显状态:  #status.textContent    (空)        ──click──▶ 运行完成提示
```

- 状态**单向且幂等**：`disabled` 后不再产生第二次 click，无需 reset 逻辑（需求未要求，避免超范围实现）
- 成功文案唯一真值来源 = `script.js` 的 `SUCCESS_TEXT`；HTML 只承载初始态，两处不冲突

## 3. 异常处理策略

| # | 场景 | 处置 |
|---|---|---|
| 1 | 环境无 Node（`validation_commands` 槽位缺失，风险#1） | 双路径：`node --check` 优先；不可用则降级为语法自查 + 环境探测说明，**如实记录返回信息，不伪造命令结果、不因此阻塞交付** |
| 2 | `file://` 白屏 / 样式丢失（风险#2） | 编码期约束消除：`./` 相对路径 + 普通 `defer` 脚本 + 禁 module + 禁网络请求 + charset 前置 |
| 3 | id 拼写不一致致 `null` 抛 `TypeError` | `resolveElements()` 集中判空，`console.error` 指明缺失 id 后安全退出，不产生未捕获异常 |
| 4 | 中文乱码 | `meta charset="utf-8"` 首位 + UTF-8 无 BOM 写入 |
| 5 | 误写根目录（风险#3） | 4 次写入路径均以 `hello-dev/` 开头；写后用 `dir` 结构核对，确认无越界产物、无临时文件残留 |
| 6 | 重复点击状态错乱 | 首次点击即 `disabled`，状态机不可回退 |
