**新增目录结构：**
```text
D:\ABC\calculator\
    __init__.py         # 导出公共接口 calculate(text)
    engine.py           # 核心逻辑：词法分析(Token) + 递归下降解析器(Recursive Descent Parser)
    cli.py              # CLI 交互入口 (REPL 循环)
```

### 2. 核心设计与数据流 (`engine.py`)
采用**词法分析 -> 语法解析 -> 求值**的标准三步走策略，不使用 `eval()` 以保障稳定性。

*   **数据流设计**：
    1.  **Input**: 接收原始表达式字符串 (例如 `(10.5 - 2) * 3 + (-4.0)`)。
    2.  **Tokenize**: `lexer.py` 概念实现。移除空格，将字符组合为 `Token(NUMBER='10.5')`, `Token(OP='-')` 等序列。
    3.  **Parsing & Evaluation**:
        *   `parse_primary()`: 处理数字字面量和 `(expr)` 嵌套。
        *   `parse_unary()`: 处理一元正负号。
        *   `parse_multiplication()`: 乘除 (高优先级)。
        *   `parse_addition()`: 加减 (低优先级)。
    4.  **Output**:
        *   成功时返回浮点数结果。
        *   失败时抛出结构化异常（如 `CalculatorError("Invalid syntax at char index...")`）。

*   **异常处理策略**：
    *   **除零错误**：在 `/` 操作符处捕获，抛出 `ZeroDivisionError`。
    *   **格式错误**：遇到无法识别的 Token 或未闭合括号，抛出 `SyntaxError`。
    *   所有异常均向上层抛出具体错误提示，绝不崩溃或产生 `NaN`。

### 3. CLI 实现 (`cli.py`)
提供极简的 REPL (Read-Eval-Print Loop) 模式，支持输入 `quit` 退出。实时反馈计算结果与错误原因。

### 4. 验证方案
*   **自动化**：通过 `python calculator/cli.py < test_input.txt` 批量验证常见算式。
*   **人工验收**：直接在命令行输入 `1 + 1`, `(10-2)/4`, `10/0` 观察响应。
