### 1.3 `hello-dev/script.js`

职责：

- 使用原生 JavaScript 实现按钮点击文案切换。
- 点击按钮后，将标题文案从 `Hello DEV` 改为 `DEV 工作流运行成功`。
- 不使用 Vue、React、npm 包或外部脚本。
- 保持 `node --check` 可通过的合法 JavaScript 语法。

计划实现：

```js
(function () {
  "use strict";

  const SUCCESS_MESSAGE = "DEV 工作流运行成功";

  function handleToggle() {
    const messageElement = document.getElementById("message");

    if (!messageElement) {
      console.warn("未找到 id 为 message 的元素，文案切换已跳过。");
      return;
    }

    messageElement.textContent = SUCCESS_MESSAGE;
  }

  function init() {
    const button = document.getElementById("toggle-button");

    if (!button) {
      console.warn("未找到 id 为 toggle-button 的按钮，初始化已跳过。");
      return;
    }

    button.addEventListener("click", handleToggle);
  }

  if (document.readyState === "loading") {
    document.addEventListener("DOMContentLoaded", init);
  } else {
    init();
  }
})();
```

关键约束：

- 使用 IIFE 避免全局变量污染。
- 使用 `textContent` 修改文本，不使用 `innerHTML`。
- 不发起网络请求。
- 不访问 localStorage / sessionStorage。
- 不使用 ES Module import/export。
- 不使用异步逻辑，因此无需 `async/await`。

## 4. 异常处理策略

### 4.1 DOM 初始化时机风险

问题：

- 脚本执行时 DOM 可能尚未解析完成。

处理方式：

- `index.html` 中脚本使用 `defer`。
- `script.js` 中兼容 `readyState === "loading"` 与非 loading 两种情况。

策略：

```js
if (document.readyState === "loading") {
  document.addEventListener("DOMContentLoaded", init);
} else {
  init();
}
```

### 4.2 找不到按钮风险

问题：

- HTML 结构被后续误改时，可能找不到按钮。

处理方式：

```js
const button = document.getElementById("toggle-button");

if (!button) {
  console.warn("未找到 id 为 toggle-button 的按钮，初始化已跳过。");
  return;
}
```

设计原因：

- 不抛异常。
- 不影响页面静态渲染。
- 满足“无控制台报错”的主要验收目标；`console.warn` 不是报错。

### 4.3 找不到标题风险

处理方式：

```js
const messageElement = document.getElementById("message");

if (!messageElement) {
  console.warn("未找到 id 为 message 的元素，文案切换已跳过。");
  return;
}
```

### 4.4 file:// 协议风险

禁用：

```js
import ... from "./module.js"
export ...
fetch(...)
localStorage 持久化
```

采用：

- 普通 `<script src="script.js" defer></script>`
- 相对资源路径
- 零网络请求
- 零模块加载

### 4.5 外部依赖风险

禁用：

```html
<link rel="stylesheet" href="https://...">
<script src="https://..."></script>
<script src="./node_modules/..."></script>
```

采用：

- 本地 `style.css`
- 本地 `script.js`
