## 2. 数据流设计

```
index.html  （文案唯一真源在 DOM）
 ├─ <h1 id="hello-title">Hello DEV</h1>
 ├─ <button id="run-btn">运行工作流</button>
 └─ <p id="hint">点击按钮触发</p>        ← 可选节点，取值前判空
        │
script.js  (IIFE，无全局污染)
  └─ readyState 分流
       ├─ 'loading' → DOMContentLoaded → init()
       └─ 否则      → 直接 init()
                │
             init()：防御性取 3 个节点
                ├─ title/btn 任一为 null → return（不抛异常）
                └─ btn.click 监听
                     ├─ title.textContent = SUCCESS_TEXT
                     ├─ title.classList.add('is-success')  ← 样式切换交 CSS，逻辑与表现解耦
                     ├─ hint && (hint.textContent = '已完成')
                     └─ btn.disabled = true                ← 单次生效，符合"不要求可逆"
```

**时序双保险**：脚本本体已在 `</body>` 前（DOM 已就绪），额外加 `readyState` 判断，防御未来有人把 `<script>` 移到 `<head>`。

**状态色变更而非文案内联样式**：`is-success` 只挂类名，颜色由 CSS 决定，避免 JS 内写 `style.color`。

## 3. 语法级别取舍

刻意使用 `var` + 函数表达式 + IIFE，保持 **ES5 可直跑级别**。

理由：`file://` 双击场景下浏览器版本不可控，本需求零依赖，任何 `type="module"` / 顶层 `await` / `import`/`export` 都只是纯风险面、收益为零。箭头函数与 `const/let` 现代浏览器均支持，但此处不为"更优雅"引入变量。

## 4. 异常处理策略

| 层面 | 策略 |
|---|---|
| **写入期** | 先建目录再写文件；任一步 `write_file` 失败即中止并原样回报错误，**不静默降级、不改路径重试、不谎报成功** |
| **运行期** | `hello-title` / `run-btn` 任一为 `null` → 直接 `return`，保障验收项 3"控制台零报错"；`hint` 为可选节点，取值前判空 |
| **编码** | 全部按 UTF-8（无 BOM）写入，规避 `file://` 中文乱码（R3） |
| **验证链降级** | 优先 `node --check hello-dev/script.js`（项目根直接执行，不 `cd`、不用 `&&`）；若不在 shell 白名单或环境无 node → 降级为人工静态审查，并在交付说明中**明确标注实际采用的方式**，不虚报"已检查"（R2） |
| **零侵入自检** | 若为 git 仓库跑 `git status` 确认改动仅 `hello-dev/` 未跟踪新增；非仓库则跳过并说明原因 |

**静态审查降级项**（无 node 时执行）：括号/花括号配对、引号配对、HTML 中 3 个 id（`hello-title`/`run-btn`/`hint`）与 JS 中 3 处 `getElementById` 字面量逐一比对、`SUCCESS_TEXT` 文案与验收项 4 逐字一致、`<link>`/`<script src>` 文件名与实际文件名大小写一致。

### `hello-dev/script.js`

```js
(function () {
  'use strict';

  var SUCCESS_TEXT = 'DEV 工作流运行成功';
  var DONE_HINT = '已完成';

  function init() {
    var title = document.getElementById('hello-title');
    var btn = document.getElementById('run-btn');
    var hint = document.getElementById('hint');

    if (!title || !btn) {
      return;
    }

    btn.addEventListener('click', function () {
      title.textContent = SUCCESS_TEXT;
      title.classList.add('is-success');

      if (hint) {
        hint.textContent = DONE_HINT;
      }

      btn.disabled = true;
    });
  }

  if (document.readyState === 'loading') {
    document.addEventListener('DOMContentLoaded', init);
  } else {
    init();
  }
})();
```
