## 二、各文件设计

### 1. `index.html`
- `<!DOCTYPE html>`、`<html lang="zh-CN">`
- `<head>` 内**必须**有 `<meta charset="UTF-8">`（R3 乱码破点）、`<meta name="viewport">`、`<title>Hello DEV</title>`
- `<link rel="stylesheet" href="style.css">` —— 正斜杠/裸相对路径，**绝不写 `hello-dev\style.css` 或绝对路径**
- `<body>` 末尾 `<script src="script.js" defer></script>` —— **不用 `type="module"`**（`file://` 下会被 CORS 拦截，直接白屏）
- 关键节点：`<h1 id="greeting">Hello DEV</h1>`、`<button id="runBtn" type="button">运行 DEV 工作流</button>`
- 文案**初始值直接写在 HTML 里**，不靠 JS 注入 → JS 即使失效，验收项 2 的「显示 Hello DEV」仍成立（降级友好）

### 2. `style.css`
- 极简 reset：`box-sizing: border-box`、`body` 去默认 margin
- `body` 用 flex 垂直居中，系统字体栈（`system-ui, -apple-system, "Segoe UI", sans-serif`，零外链）
- 按钮态：`hover` / `active` / `:focus-visible` 轮廓（可访问性）+ `:disabled` 变灰
- 不写媒体查询（需求明确「不做响应式适配」）

### 3. `script.js`（唯一含逻辑的文件）
数据流（单向、一次性）：

```
DOMContentLoaded
  → init(): document.getElementById('greeting' / 'runBtn')
  → 元素存在性守卫
  → runBtn.addEventListener('click', handleRun)
  → handleRun(): 已执行过? → return
                 greetingEl.textContent = 'DEV 工作流运行成功'
                 runBtn.disabled = true
                 runBtn.textContent = '已运行'
```

关键决策：
- 常量集中在文件顶部（`SUCCESS_TEXT`、`DONE_TEXT`），文案不散落在逻辑里。
- 用 `textContent` 不用 `innerHTML`（无 HTML 解析面）。
- `'use strict'` + IIFE 包裹，避免污染 `window`（`file://` 下无需构建也能保持作用域干净）。
- **不使用** `fetch` / `XMLHttpRequest` / `import` / `export` / 任何第三方 API；纯 ES2015。

异常处理策略：
- DOM 未就绪兜底：`document.readyState === 'loading'` 时挂 `DOMContentLoaded`，否则立即 `init()`（双保险，即使 `defer` 语义被某个浏览器边缘行为破坏也不炸）。
- 元素缺失守卫：`if (!greetingEl || !runBtn) { console.error('[hello-dev] 缺少必要 DOM 节点'); return; }` —— 不抛异常，保证控制台无红色报错。
- 幂等守卫 `hasRun` 标志：重复点击不产生状态漂移。
- 不做 try/catch 包裹（无 IO、无异步、无网络，包 try/catch 是噪音）。
