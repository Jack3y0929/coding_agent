## 1. 任务概述

### 1.1 任务目标

# 需求概括 · hello-dev 演示页

## 1. 项目定义
在项目根目录下新建独立文件夹 `hello-dev`，放一个纯静态演示页：显示 "Hello DEV"，点按钮后文案切换为 "DEV 工作流运行成功"。零侵入，跑通 DEV 工作流本身是首要目的。

## 2. 核心功能范围

**做什么**
- 新建目录 `D:\ABC\hello-dev\`
- 4 个新文件：`index.html`、`style.css`、`script.js`、`README.md`
- 页面初始渲染文本 "Hello DEV"
- 一个按钮，点击后该文本变更为 "DEV 工作流运行成功"（单次状态替换，非累加/非切换回退）
- `index.html` 通过 `<link>` / `<script src>` 分别引用同目录 css、js（相对路径，可直接双击本地打开）
- `README.md` 说明目录用途、打开方式、验收点

**不做什么**
- 不改动 `D:\ABC` 下任何现有文件（构建配置、路由、package 清单、公共 css/js 一律不碰）
- 不引入任何 CDN / 第三方库 / 框架 / 打包工具
- 不做后端、不做持久化、不发网络请求
- 不做响应式适配、主题、多语言、无障碍以外的额外视觉设计
- 不做单元测试与 CI 配置（`validation_commands` 未指定）

## 3. 技术约束
- 用户侧无技术约束，按最短路径取默认：**原生 HTML5 + CSS + 原生 ES6 JavaScript，无构建步骤**。
- 命名与文案为硬要求，逐字对齐：`Hello DEV`、`DEV 工作流运行成功`（中文全角空格/无空格按原样，不自行美化）。
- 已核实：项目内不存在 `Hello DEV` / `DEV 工作流运行成功` 相关文本，也不存在任何 HTML 文件 → 新目录无命名冲突、无样式污染风险，属全新页面。
- 落地位置：`D:\ABC\hello-dev\`，绝对路径以目标项目根为准。

## 4. 关键验收标准（按优先级）
1. `hello-dev/` 目录下 4 个文件齐全：`index.html`、`style.css`、`script.js`、`README.md`，无多余产物。
2. 项目现有文件 **零 diff**（仅新增，不修改、不删除、不重命名）。
3. 浏览器打开 `index.html`，首屏可见文本 "Hello DEV"。
4. 页面存在可见按钮；点击后目标文本变为 "DEV 工作流运行成功"，控制台无报错。
5. css/js 经外部文件引用生效，不把逻辑内联回 `index.html` 交差。

## 5. 风险清单
1. **工作目录歧义**：项目根为 Windows 路径 `D:\ABC`，若执行环境 cwd 不是该根目录，文件夹会建错位置 → 落地前用绝对路径确认。
2. **文案字面不匹配**：`DEV` 大小写、中文串里的空格属肉眼易漏项，需按原文逐字校验。
3. **脚本加载时机**：`<script src>` 若放在 `<head>` 且未加 `defer`，绑定按钮时 DOM 未就绪 → 静默失效、无报错，验收 4 直接挂。
